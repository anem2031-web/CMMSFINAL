## Documentation Update 001 — 2026-09-03

### تم توثيق

- اعتماد استخدام نفس آلية الصرف/التحويل الحالية للمخزن الفرعي، بما فيها QR/Lot Tracking عند الطلب.
- اعتماد عدم تنفيذ أي خصم مخزون مباشر داخل PM V2.
- اعتماد بدء المستودع طلب الشراء الخارجي من PM V2 مع إنشاء/ربط بلاغ الجسر.
- اعتماد استمرار صلاحيات Path B الحالية دون إضافة صلاحية PO لدور المستودع.
- اعتماد الربط الكامل بين مهمة PM V2 وبندها وطلب المادة وبلاغ الجسر وPurchase Order.
- اعتماد بروتوكول أوامر قاعدة البيانات اليدوي خطوة بخطوة وتحديث ملف الـSchema عند أي تغيير.
